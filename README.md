# alfa guides

Правила, инструкции и нотации по разработке в AflaGenesis

# Работа с git-ом

Придерживаемся классического git flow. 

* git successful branching model - http://nvie.com/posts/a-successful-git-branching-model/
* Все комиты в master-ветку, исключая hotfix, имеют привязку к задаче.
